# quant-lab-ai
quant-lab-ui — lightweight web UI for the quant-lab-ui — lightweight web UI for the Quant Lab IPO monitor. Shows same-day U.S. IPOs, computes offer amount (price×shares), highlights those ≥ $200M, displays alert delivery status and fail-safe logs. Timezone-aware (US/Eastern market day, scheduled 09:00 Asia/Dubai).
